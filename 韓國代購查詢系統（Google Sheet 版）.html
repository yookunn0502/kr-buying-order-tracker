韓國代購查詢

輸入購買人名稱即可查詢訂單與貨態

代購注意事項

・商品皆為韓國官方購入，若遇缺貨將另行通知。
・代購商品需先付款才會進行下單。
・韓國出貨與國際物流時間約 7～21 天不等。
・海外商品可能因運送產生外盒輕微壓損，完美主義者請斟酌下單。
・已下單商品除重大瑕疵外不接受取消訂單。
・若有任何問題可透過 IG / LINE 聯繫。

Google Sheet 後台設定方式

1. 建立 Google Sheet
2. 欄位名稱請設定：
Name ｜ Product ｜ Status
3. 範例：

小安 ｜ Matin Kim 包包 ｜ 已匯款
小安 ｜ Mardi T-shirt ｜ 待出貨
Yuki ｜ Gentle Monster 墨鏡 ｜ 已購買
4. 發布成網頁：
Google Sheet → 檔案 → 共用 → 發布到網路
5. 使用 sheet.best / opensheet 等服務轉成 JSON API
6. 將下方 API_URL 改成你的網址即可
